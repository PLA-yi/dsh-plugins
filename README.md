# DSH 插件：创作台、口碑雷达

两个给 DeepSeek Harness（下面简称 DSH）用的插件。都是纯 JavaScript，不用打包，装上就能用。

| 文件夹 | 是什么 |
|---|---|
| `创作台/` | 把「小易工作台」搬进 DSH：选题广场、作品（文章、小红书卡片、视频脚本）、视频、素材、AI 记忆、动态、设置。AI 用 DSH 里配好的模型，不用另外填密钥。 |
| `口碑雷达/` | 每天去微博、B 站、知乎、小红书、抖音、公众号和新闻里搜你填的名字，把提到它的内容和评论收回来，让 AI 判断有没有人在骂你。免费来源优先，付费接口（TikHub）补缺，可以设月上限。 |

## 安装

DSH 里「插件 → 添加插件 → 安装第三方插件」，填插件文件夹的完整路径。装之前看一眼各自的 `cordis.patch.yml`。

- **创作台** 要配合小易工作台一起用（插件在后台起一个工作台，默认端口 5295）。小易工作台不在这个仓库里，装之前把 `cordis.patch.yml` 里的 `workbenchDir` 改成你本机工作台所在的文件夹（里面有 `server.mjs`）。
- **口碑雷达** 装上就能用，第一次打开会问你要盯谁。B 站、公众号、新闻不用登录；微博、知乎、小红书、抖音要在插件打开的 Chrome 窗口里自己登录。

两个插件都依赖 DSH 自带的 `@deepseek-ai/dsh-llm`，已经写在 `peerDependencies` 里。

## 口碑雷达的规矩

只做正常用户能做的事：不伪装浏览器、不隐藏自动化标记、不绕验证码、不重放平台内部接口。遇到验证码就停下，让你自己在 Chrome 窗口里处理。

## 文件说明

各自文件夹里的 `使用说明.md` 写了怎么用、每个文件管什么、改了以后要不要重启。口碑雷达的测试：进 `口碑雷达/` 跑 `node --test test/`。
