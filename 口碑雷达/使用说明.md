# 口碑雷达 使用说明

每天去微博、B 站、知乎、小红书、抖音、公众号和新闻里找提到你的帖子和评论，用 DSH 里配好的模型（默认 DeepSeek）判断哪些在骂你。打开「今天」页，第一句话就告诉你今天有几条在骂你、骂了什么、在哪。

## 怎么装

1. DSH 里点「插件 → 添加插件 → 安装第三方插件」，填这个文件夹的完整路径（就是放着 `index.js` 的那个文件夹）。
2. 重启 DSH，左侧栏会多一个「口碑雷达」。
3. 确认 DSH「设置 → 模型」里选好了默认模型。插件判断用的就是它，没选的话抓到的内容会显示「没判断」。

小红书、抖音、微博、知乎要用到电脑上的 Google Chrome，没装的话先装一个。

## 第一次怎么设

1. 打开「口碑雷达」，先填要盯的对象：名称（品牌名、账号名、人名都行），再填几个别名或产品名，用逗号隔开。
2. 去「设置」：
   - 排除词：同名但不是你的东西，比如盯「小米」时排除「小米粥」。
   - 平台开关：不想看的平台关掉。
   - 自动检查：默认每天 9:00。DSH 开着就会按时检查；那个点 DSH 没开，下次打开时补一次。
   - 只看最近几天发的：默认 7 天，更早的帖子不收。
3. 回到「今天」点「立即检查」，第一次大概要几分钟（为了不给平台添麻烦，每次请求之间都会停几秒）。

## 每个平台怎么拿数据

| 平台 | 免费方式 | 要不要登录 |
|---|---|---|
| B 站 | 公开搜索和评论接口 | 不用（不登录每个视频只能看到最新几条评论） |
| 公众号 | 搜狗微信搜索 | 不用（只有标题和摘要；搜狗不能按时间筛，老文章会被「只看最近几天」滤掉） |
| 新闻资讯 | 必应新闻、Google 新闻的 RSS | 不用（Google 要这台电脑能连上；百度新闻要人机验证，没接） |
| 微博、知乎、小红书、抖音 | 插件自己的 Chrome 窗口 | 要，你自己扫码登录一次 |

## 小红书、抖音、微博、知乎怎么登录

1. 「设置 → 平台」里，在那个平台那一行点「打开登录窗口」。
2. 会弹出一个 Chrome 窗口。它用的是插件自己的资料，和你平时的 Chrome 分开，你平时的账号和书签它都碰不到。
3. 在这个窗口里用手机 App 扫码登录。登好以后回来点「我登好了」，状态变成「已登录」就行，窗口可以关掉。
4. 以后检查时，插件会在这个窗口里打开站内搜索页和帖子页看一眼，看完自己关。检查的时候别去关它。

碰到下面两种情况，插件会停下来，在页面上告诉你：

- 「被验证码挡住」：去弹出来的那个 Chrome 窗口里自己点一下验证，弄完再点「立即检查」。插件不会替你点验证码。
- 「登录过期」：点「打开登录窗口」重新扫一次码。

插件只看你自己账号能看到的内容，只读页面上显示出来的东西，不伪装浏览器、不绕过验证码和登录。知乎的评论要点开才显示，插件不替你点，所以知乎只收搜索结果。

## 花钱规矩（付费数据接口，可以不用）

免费方式拿不到的平台（没登录、被验证码挡住、暂时拿不到），可以用 TikHub 的数据接口补。它按次收费，钱从你自己的 TikHub 账户扣。

- 不填密钥这一路就不跑，一分钱都不花。
- 密钥在 user.tikhub.io 后台「API 令牌」里创建，粘到「设置 → 付费数据接口」。密钥只存在这台电脑上。
- 每月上限默认 5 元，到上限就停，这次检查照常做完，不报错，下个月自动恢复。上限填 0 就是完全不用。
- 每调一次都记账，「设置」里能看到本月已用多少、调了几次。插件按「每次大约多少钱」估算（默认 0.01 元），实际以 TikHub 后台为准，价格变了就在设置里改一下。
- 免费方式能拿到的平台不会去调付费接口。每个平台一次检查最多调 6 次。

## 模型判错了怎么办

在「今天」或「全部评论」点开一条，下面有「判错了？改成」，可以改成在骂、中性、夸、和我无关。改了以后今天的数字和统计都按你改的算。想改回去点「改回模型的判断」。

模型偶尔会失败（网络、太忙），那批内容会显示「没判断」，下次检查会自动再判。

## 数据存在哪

都在 DSH 自己目录下的 `reputation-radar` 文件夹里：`settings.json`（设置）、`items.json`（抓到的内容）、`state.json`（平台状态、日报、花费）、`secret.json`（付费接口密钥）、`chrome/`（插件那个 Chrome 窗口的登录信息）。想把登录全清掉，关掉 DSH 后删掉 `chrome/` 文件夹。

## 给改插件的人

- 测试：在这个文件夹里跑 `npm test`（不联网，用假的平台和假的模型）。
- 实测免费源现在还能不能拿到：`npm run probe` 或 `node test/实测免费源.mjs 庞巴迪`（会联网，大概 1 分多钟）。
- 页面在 `client.js`，后台在 `index.js` 和 `host/`，每个文件开头都写了它管什么。
