# 创作台的工作台

创作台插件的后台程序：管理文章、小红书卡片、视频、选题广场、素材和记忆。插件在后台把它起来，页面通过插件转请求。最早来自「小易工作台」，现在是创作台自己维护的独立一份，直接在这里改。

## 打开

```bash
xy ui          # 启动网页工作台并在浏览器打开：http://127.0.0.1:5288
```

需要本机的 Node（已有）和 Google Chrome（渲染卡片用）。唯一的依赖是 Claude 官方 SDK（`@anthropic-ai/sdk`，已装在 node_modules）。

## 从 GitHub 拉下来后

```bash
npm install                              # 工作台自己的依赖
npm install --prefix templates/runtime   # 文章构建用的依赖（marked、juice）
npm install --prefix video/runtime       # 视频板块用的依赖（HyperFrames、ffmpeg；会顺带装编译 whisper 用的 cmake）
```

`data/`（登录令牌、AI 设置、配音密钥、记忆、素材）不进仓库，第一次启动时自动新建。

## 项目从哪来

自动扫描 `AI Coding/` 下一层的文件夹：

- 有 `article.md` 的是**文章**（构建 = `node build.mjs` + `python3 embed.py`）
- `index.html` 里有 `<section class="card" data-n="…">` 的是**小红书卡片**（构建 = 每页渲染成 1440×1920 的 jpg 放进 `out/`）

别处的文件夹用 `xy add <路径> --type article|card` 加进来。

每个项目的状态、标签、计划日期、发布记录、笔记、操作记录存在项目文件夹里的 `.workbench.json`，不动项目原有文件。全局操作记录在 `data/activity.jsonl`。


## 视频

侧栏的「视频」板块，两个页签：**我的视频**（自己做）和**拉片**（拆别人的）。

### 我的视频

选一篇文章，让 Claude Code 写代码把它做成视频，用的是开源的 [HyperFrames](https://github.com/heygen-com/hyperframes)（写 HTML，渲染成 MP4）。

- **图文动画解读**：AI 读文章、写旁白、做动画画面；点「生成配音」合成旁白，AI 再按真实时长对齐；点「导出成片」出 MP4
- **口播剪辑**：上传口播录像、录音、录屏、图片（可以多个）。工作台统一转成 H.264、找出停顿、用本机的 whisper 转出逐字时间轴；AI 先出一份剪辑方案（留哪些、剪掉哪些口误和重复、哪里插画面），作者同意后再剪，配字幕和画面。原素材不会被改
- **剪辑手法**：去停顿快切、推近强调、逐句大字幕、花字关键词、插入配图和录屏、画中画、分屏对比、章节进度条、音效点。新建时选，之后可以在视频页里开关；拉片学到的手法也会出现在这里
- 画幅：竖屏 1080×1920 或横屏 1920×1080，新建时选
- 配音：「配音设置」里接付费服务（OpenAI 兼容的 `/audio/speech` 接口，比如硅基流动、OpenAI），密钥存在 `data/tts.json`；没接时用电脑自带的语音
- 每条视频是一个文件夹 `视频-<名字>-竖屏/横屏`，和文章放在同一层，里面是完整的 HyperFrames 项目，成片在 `renders/`

### 拉片

贴一条视频链接（或上传视频文件），工作台把它下载下来，找出每个镜头的切点、每个镜头截一帧、把口播转成文字，再让 Claude Code 写出：开头怎么抓人、结构、每个镜头的画面和剪法、节奏数据、能学走的手法。手法可以一键存进「剪辑手法」库。

- 抖音：弹出一个看得见的普通 Chrome 窗口（工作台自己的配置 `data/chrome-video`，不碰平时用的浏览器）打开视频页，旁听页面自己拿到的视频地址。不伪装浏览器、不处理验证码；抖音要验证或登录时，点「打开抖音窗口」自己处理一次
- YouTube、TikTok、X 等：用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。B 站在境外网络下会被地区限制，小红书要登录，这两种先手动下载再上传
- 20 分钟以内的视频。每次拉片是一个文件夹 `拉片-<平台>-<时间>`
- 拿下来的视频只用来分析学习，不要搬进自己的成片

要用本机登录好的 Claude Code（「AI 设置」里登录）。做视频时它只在视频文件夹里读写，能跑的命令只有 `hyperframes` 和看文件、拷素材这几样；拉片时只能读材料、写一份分析。

## 网页

- 视图：画廊 / 表格 / 看板（拖动改状态）/ 日历（拖到某天就排上计划发布）。快捷键 1–4 切换
- 侧栏按类型、星标、状态、标签筛选
- ⌘K（或 /）：搜项目、搜正文、执行命令；N：新建
- 项目页：改标题、状态、标签、计划日期，记发布记录；渲染 / 构建、打包、浏览器预览、编辑源文件、在访达打开
  - 卡片：像 Figma 一样把所有页平铺在画布上，拖动平移、⌘ + 滚轮缩放、点开放大；可切换「源页面（实时）」看还没渲染的改动
  - 文章：手机框里看公众号版 / X 版，下面是产出的所有图
  - 笔记（Markdown，自动保存）、文件列表、操作记录
- 命令行改了东西，网页 4 秒内自动刷新

## 命令行（给人，也给 AI）

```text
xy list [--type 文章|卡片] [--status 待发] [--tag 标签] [--pinned]
xy show <项目>            xy files <项目>          xy search <文字>
xy log [<项目>]           xy status
xy new <article|script|card> <名字> [--from <模板项目>]   # script 是视频脚本（口播稿）
xy set <项目> [--title …] [--status 灵感|草稿|待发|已发布] [--tags a,b] [--plan 2026-11-20] [--pin|--unpin]
xy tag <项目> +标签 -标签
xy note <项目> [文字]
xy publish <项目> --platform 小红书 [--url 链接] [--date 2026-11-07]
xy build <项目>           xy pack <项目>
xy open <项目> [--finder|--preview|--edit|--zip|--web]
xy set <项目> --build "命令" | --pack "命令"     # 自定义构建 / 打包命令，只能在命令行改
xy ui                     xy add <路径> [--type …]

xy ai                                  # 有哪些模型、哪个能用
xy ai use deepseek                     # 设默认
xy ai set deepseek --key sk-…          # 填密钥（也能 --model / --base-url）
xy ai test [模型]
xy ai 去AI味 "一段文字"                  # 还有 润色 精简 扩写 故事感 抓人；改 "文字" --要求 "…"
xy ai 体检 <文章>     xy ai 标题 <文章>
xy ai 卡片 <卡片项目> --page 2 [--n 元素编号] "怎么改"
xy undo <项目>        xy versions <项目>
```

项目名写一部分就行（`xy show deepseek`）；匹配到多个会提示。

**AI 使用时**每条命令加 `--json`，输出 JSON；出错时输出 `{"error": "…"}` 并以退出码 1 结束。建议流程：`xy list --json` 找项目 → `xy show <项目> --json` 看详情和 `dir` → 改项目文件 → `xy build` → `xy pack` → `xy set --status 待发`。

## AI 创作

右上角「✦ AI 设置」选模型、填密钥：

- **Hermes**（默认）：用你本机已经配好的 Hermes，不用填密钥。每次 10–20 秒，整篇体检约 50 秒。它只开一个无害的 todo 工具集、在空目录里跑，不会去动你的文件
- **Claude**：官方 SDK，默认 `claude-opus-5-5`，开了拒答时的服务端兜底；边写边出字
- **DeepSeek、通义千问、Kimi、豆包、智谱、OpenAI**：OpenAI 兼容格式，填密钥（和模型名）就能用；也可以「加一个别的接口」
- 密钥存在 `data/ai.json`（权限 600），也可以用环境变量（设置页里写了每家的变量名）

**文章 · 写作页**：左边直接改 `article.md`（自动保存，⌘S 立即存），右边是实时预览。

- 选中一段 → 润色 / 去 AI 味 / 精简 / 扩写 / 加故事感 / 更抓人 / 按我的要求改；结果在右侧面板，点「替换选中」或「插在后面」，⌘Z 能撤回
- 续写：从光标处往下写一两段；整篇体检：挑 AI 味、冗余、逻辑、需要核对的数字；起标题
- AI 的改写规则来自你对文章的要求：不改事实数字、不编造（要资料的地方标【待补】）、不用「不是…而是…」和金句收尾等

**卡片 · 精修页**：

- 单击选中卡片上的任意一块，右边调字号、颜色、加粗、对齐、上边距；双击直接改字；Delete 删除
- 「让 AI 改这一块」：写一句要求或点快捷词（更口语、更短、更有冲击力……）；什么都不选就改整页
- 改动直接写回 `index.html` 对应的那一段，其他地方一个字不动
- 每次修改前自动存一个版本（`.workbench/versions/`，最多 80 个）：「撤销」或 ⌘Z 回到上一步，「版本」里能回到任意一次
- 改完点「渲染成图」重新出 jpg

## 文章写作室（四步）

点进一篇文章，上面是 ① 资料 ② 写作 ③ 体检 ④ 发布，按顺序走：

1. **资料**：输入要查的问题，AI 联网查（Hermes 开 web 工具集 / Claude 用网页搜索），结论后面带来源链接，存在 `.workbench/research.json`。「让 AI 用这条」会带着资料去写作页和 AI 助手说
2. **写作**：左边大纲，中间是排版好的文章（直接改字），右边 AI 助手。和助手说哪里不满意，它的修改会以「修改建议」卡片标在原文下面：删掉的划红线、新加的标绿，逐条 ✓ 接受 / ✗ 不要，也能「全部接受」。选中文字点「润色 / 去 AI 味 / 精简…」、点「续写」，结果也都是建议，接受才写进文章
3. **体检**：正文字数、阅读时长、最长段落；去 AI 味指标对照人类文章（顿号串名词、分号、破折号、句式重复、句长变化），比上次是好了还是差了；问题清单来自检测脚本和「让 AI 通读挑问题」，每条能「定位」到原文、「AI 改」生成修改建议
4. **发布**：公众号 / X 分开，左边平台预览，右边按顺序的清单：标题字数、作者、摘要（可改）、封面尺寸、复制正文（公众号版把图片嵌进去）、下载按顺序编号的配图包（X 的序号对应正文里的图片占位）、发完记一笔

建议、对话、体检记录都存在项目的 `.workbench/` 里，换个窗口打开还在。

## 查资料和读原文

助手读网页用 `read_page`（`plaza.readUrl`），拿原文全文而不是摘要，一层层兜底：GitHub 链接走本机登录的 `gh` 接口（仓库简介和 README、文件、issue/PR 和评论、版本说明，分支名不对时退到默认分支）；要登录的站（X、微博、知乎、小红书）先走 Jina Reader；其余先直接抓，正文太少就用无头 Chrome 跑完 JS 再取字（最多等 25 秒），再不行 Jina Reader，最后让 Claude 用网页抓取工具读。原文存进项目的 `.workbench/sources/`（一天内重复读直接用缓存），长文分段读。`save_research` 记资料时标来源等级（官方一手 / 社区一手 / 报道 / 转述）和原文摘录，资料页上能看到；关键数字只有转述的写明“待核”。查资料的顺序写在助手规则里：资料页 → 选题广场 → 公司官方渠道（site: 限定）→ 媒体报道。

## 依赖库

新建文章的 `node_modules` 链到工作台自带的 `templates/runtime/node_modules`（marked、juice 等），不再链到别的项目——那个项目一删，这篇就构建不了，编辑器也会退回到只认标题的简陋排版（加粗、分隔线、列表都原样显示）。编辑器排版时这篇自己的 marked 找不到，也会退到工作台这份。

## 视频脚本（口播稿）

视频脚本是文章的一种形式：正文同样写在 `article.md`，`.workbench.json` 里 `form` 是 `script`，所以编辑器、AI 助手、资料页、体检、记忆都直接可用。

- 骨架：开头钩子（0–3 秒）、正文分段（每段先写口播原话，再用「> 画面：……」写配什么画面）、结尾、封面和标题、发布文案和话题。从自媒体插件的视频选题新建时，开口第一句、口播提纲、建议时长、封面字和标题备选会直接填进骨架。
- 时长：按每秒约 4.5 个字估（`core.mjs` 的 `spokenText` / `speakSeconds`），只算口播原话，不算画面提示、整行括号的占位说明，也不算「封面和标题」「发布文案和话题」两节。列表和项目页显示「口播约 X」。
- AI：助手、划选改写和对话在写作规则之外再加一份口播规则（`ai.mjs` 的 `SCRIPT_RULES`）：短句、口语、开口第一句直接给结果、每段带画面提示、按时长删改。
- 提词页（最后一步）：一段一段看口播原话、画面提示和每段时长；「复制口播稿」只复制要说的话，「复制分镜表」带画面，「大字提词」全屏黑底大字，方向键翻段。
- 命令行：`xy new script 题目`；`xy list --type script`。

## 新建

新建弹窗以题目和要求为主：大号题目框、要求框（写给谁看、切入角度、要写到的内容、参考链接、篇幅、不要写的，下面有快捷插入），类型是右上角的「文章 / 视频脚本 / 小红书卡片」切换。要求存进项目的 `brief`（`.workbench.json`），助手每轮都带在提示最前面。「建好以后」三选一：先和 AI 聊大纲（默认）/ 直接写初稿 / 我自己写。前两种建好直接进写作页（卡片进精修页）并替作者发出第一句话；「先查资料、出大纲」时助手先查一手资料，用 `save_research` 记进「资料」页（每条写清时间、口径、出处），汇总后再定标题：小标题写成直接给结论的陈述句，读者只看标题就知道这节讲什么；「# 」行放推荐标题，其余备选写在 deck 下面。然后把大纲稿直接写进文章（标题、deck、开头怎么起、每节小标题下 3–5 条要点、哪里配图），不写成段正文，再发几个问题卡片和「大纲这样行吗？」。只要文章还是大纲稿，作者可以直接改，也可以反复问“大纲有什么问题”“这里改具体点”，助手只改大纲；作者说“写正文”才一节一节展开。对话记录里存这一轮完整说过的话（工具调用前写的大纲也留着），不只最后一段。找选题收在下面，点开才用；点一个选题，题目和要求会自动填好（切入角度、为什么现在写、开头可以用）。⌘↵ 创建。

## 复盘已发布的作品（越写越顺手）

`learn.mjs`。文章或卡片标成「已发布」后，工作台过几秒在后台复盘一次；命令行 `xy publish` 标的、以前就发过的，工作台启动 1 分钟后和每半小时补一次（都跟着「AI 记忆」里的“自动整理”开关）。也可以在「AI 记忆 → 复盘过的作品」里点「重新复盘 / 现在复盘」，或者 `xy learn [项目]`。

复盘读的东西：成稿；从初稿（历史版本里最早一个有成稿四成篇幅的版本）到成稿改过的段落，按段落相似度配成「前 → 后」对，以及删掉的段落；作者对助手说过的话；卡片上的决定；撤销过的改动。产出两样：作品档案存 `data/works.json`（写了什么、切入、结构、标题怎么起、做得好的地方、费劲的地方、几段作者认可的原文），换一篇也成立的偏好合并进全局记忆（来源标「复盘学到的」）。写新文章时助手的系统提示里带最近 6 篇同类作品的档案和 6 段原文片段。工作台和命令行用 `data/learn.lock` 互斥，同一时间只复盘一篇。

## 复制到推特（X 长文）

文章页右上角「复制到推特」调 `xpost.mjs`，不依赖各篇文章自己的构建脚本。X 长文编辑器粘贴时只认二级标题、粗体、斜体、链接、列表、引用，所以：一级标题单独给（填 X 的标题栏）；三级以下标题改粗体段落，章节标题去掉「 | ENGLISH」；导语改斜体；目录改列表；参考资料改「参考资料」小节加带链接的列表；刊头和分隔线去掉；表格用文章自己的 theme.css 截成图片。图片粘不进 X，正文里留「【插图 03】」占位、下一行斜体图注，图片按号放进 `out/x/`（SVG、静态 WebP 转 PNG，动图用构建出的 GIF，封面 cover-x.png 放成 00-cover.png）。复制后弹窗左边是仿 X 长文的排版预览（封面、标题、作者行、正文，「【插图 NN】」换成真实图片），右边按步骤给：标题、封面、正文、每张插图的「复制」按钮（浏览器剪贴板只认 PNG，动图要从文件夹拖进去）；剪贴板被拦时弹窗照开，正文再点一次复制。「发布」页的 X 长文预览和复制也用这一份；写作页右上的「公众号 / 推特 / 代码」三档里，「推特」用的是和「公众号」同一个编辑器，只是换成 X 长文的样子（不加载 theme.css，顶上放 5:2 封面，标题下加作者行，图注、目录、参考资料按 X 的样子显示），照样能直接改字、回车拆段、删段、框选问 AI，改的都是 article.md。表格截图按内容缓存在 out/x/.cache/。

## 模型菜单

对话框下面的模型菜单每次打开都重新读一遍配置，刚登录、刚填好密钥的模型马上出现。能挑多个模型的接口按接口分组列出：Claude（API）可以选 Opus 5.5、Sonnet 5.5、Fable 5.1、Haiku 5.5，Claude Code 可以选跟着订阅、Opus、Sonnet、Fable、Haiku，DeepSeek 可以选 chat 和 reasoner。选中的值是「接口id::模型」，只影响这一次的调用，不改「AI 设置」里的默认模型；`ai.mjs` 的 pick() 负责拆开。

## 用 Claude 订阅额度（Claude Code）

模型菜单里的「Claude Code（订阅额度）」调用本机 Claude Code 的无界面模式（`claude -p`），用你自己 Claude 账号的订阅额度。优先用终端里装的 `claude`，没装就用 Claude 桌面 App 自带的那份。第一次在「AI 设置」里点「登录」（或终端运行 `xy ai login`），浏览器里用 Claude 账号确认；浏览器没打开时，设置里有备用链接和填验证码的框。这台电脑上一份 Claude Code 都没有时，按钮变成「一键安装并登录」，跑官方安装脚本 claude.ai/install.sh 装到 `~/.local/bin/claude`，装完接着登录。调用时不带桌面 App 的环境变量，在空文件夹 `data/claude-code-sandbox` 里跑，内置工具全关（要联网时只开搜索和读网页），不加载 MCP、不存会话。润色、去 AI 味、体检、找选题、记忆整理这些文字任务直接用它出字。

写作页和卡片精修页的助手选它时也能直接动手：`agent.mjs` 的 ccLoop 起一个 Claude Code，把工作台的工具通过 MCP 工具桥（`tools/mcp-bridge.mjs`）交给它。工具桥自己不干活，把调用转回 `/studio/agent-tool`，在这一轮任务里执行，所以改动照样存历史版本、能整轮撤销，进度照样显示在界面上；只认这一轮的随机密钥，任务结束就失效。Claude Code 自带的读写文件、终端工具全关，只留 WebSearch、WebFetch；不读作者的用户设置、钩子、插件和技能命令（`--setting-sources project`、`--disable-slash-commands`），关掉工具延迟加载（`ENABLE_TOOL_SEARCH=false`），否则工作台的工具会被藏起来。参考图通过 `--input-format stream-json` 和消息一起发过去。订阅有用量上限，用完会提示。

## 写作页的 AI 助手和素材库

写作页右边的 AI 助手选 Claude 时能直接动手（`agent.mjs`）：改正文、改样式 `theme.css` 和排版脚本 `build.mjs`，联网找官网配图存进素材库再插进文章，调用生图接口生成配图。每一轮改过的文件都记下原样，回复下面有「撤销这次改动」；改之前也照常存历史版本。选其他模型时还是老办法：修改以建议卡片标在原文里，逐处确认。

对话框可以附参考图和视频（点回形针、直接粘贴或拖进来；视频在浏览器里拆成最多 12 个关键帧，带“第几秒”说明发给 AI，视频本身不上传），也可以在消息里贴参考链接。助手会看图，链接会用无头 Chrome 截图看版式；改完模板后它会截一张自己构建出来的成品，和参考对比着再调。参考图存在各项目的 `.workbench/attachments/`。

需要作者拍板的事，助手用 ask_decisions 做成「等你定」卡片（每件 2–3 个选项），作者点选后点一次「把决定发给 AI」，它接着按决定做；答案存在各项目的 `.workbench/decisions.json`。

助手的任务在服务端独立运行（agent.mjs 的 RUNS），和网页连接脱钩：页面刷新、网络断开都不影响，页面打开时会用 `studio/agent-status` 自动接上进度；只有点「停下」（`studio/agent-stop`）才停。作者的消息一发出就先写进对话记录，哪一轮没做完会显示「重新发送」。

生图接口在 `images.mjs`，兼容四种格式：OpenAI 兼容（OpenAI、豆包 Seedream、硅基流动、智谱 CogView 等）、Google Gemini、阿里云百炼（通义万相）、MiniMax，也能自己加。密钥存在 `data/image.json`（权限 600）。生图要计费，默认 AI 助手要生图时先出一张确认卡片，点了才生成；在「生图设置」里可以关掉。

素材库（`assets.mjs`，侧栏「素材库」）全局一个：AI 生成的图、网上存的图在 `data/assets/`，各篇文章 `img/` 里的图也一起列出来，按文章和来源筛。插进某篇文章时复制到那篇的 `img/`。写作页工具栏「配图」可以挑一张插到光标所在段落后面。命令行：`xy assets`、`xy img`。

## 全局记忆和跨项目参考

`memory.mjs`，存在 `data/memory.json`。每条记忆有：种类（我是谁、写作风格、不要这样、排版和视觉、小红书卡片、口头说法、想法和选题、做法和经验）、层级（守则 / 卡片）、范围（全部 / 文章 / 卡片 / 只这一篇）、状态（生效 / 已归档），以及为什么、怎么做、自查项，和证据计数：被印证几次（在哪几篇里）、被推翻几次、自查拦下几次、带进提示几次、带着它的那轮被撤销几次。

怎么进来：作者说"记住"（`remember`）或手动加的直接是守则。对话后自动整理（`memorize`，Haiku）、发布后复盘（`learn.mjs`，Sonnet）、从作者手改里学（`edits.mjs`，Sonnet：作者保存时把 AI 写的段落和改后的配对，只改了数字、编号、标点的配对丢掉，攒够停手十分钟后找反复出现的改法；AI 照着某条记忆写却被作者改回去的，那条记一次推翻）学到的东西直接生效，先当卡片，不需要作者审批。每次写入都记进「最近学到」日志，作者在「AI 记忆」里点「不对」当场撤。写入时查重（二元组相似度：同一种类 ≥0.45、不同种类 ≥0.6 算同一件事，记一次印证不新增；实测同义改写在 0.45–0.62，真正不同的两条都在 0.3 以下）、查冲突（模型标 `replaces`，旧的记推翻）、判范围（`guessScope`：带着某篇的标题词、原话、图号节号的归那一篇）。

怎么用：每轮 `memory.select` 按这一轮的事挑记忆拼进系统提示：固定核心（我是谁 + 证据最足的 4 条守则）+ 这篇的约定 + 口头说法 + 和作者这句话、当前阶段（出大纲 / 改标题 / 配图 / 润色 / 查资料 / 做卡片 / 写正文，按关键词判断，大纲页传 outline）、正文小标题相关的经验，共约 14–18 条，带"怎么做"。不再指望助手自己调 `recall_memory`。带了哪些记在 `turn.memIds` 上，这一轮被撤销时它们记一次"被撤销"（两次算一次推翻）。

怎么升降：卡片在两篇以上文章里被印证、没被推翻过 → 守则；守则被推翻两次以上且不少于印证 → 卡片；卡片推翻 ≥3 且多于印证 → 归档。「整理一下」（`consolidate`，Sonnet）合并重复和互相矛盾的（按作者最后一次说法）、拆开过长的、分好层和范围、证据不够的守则降成卡片、守则最多 15 条、45 天没用到的卡片归档；整理前备份到 `data/memory-backups/`，可撤销。

助手改完正文却没调 `self_check` 时，收尾（`finish`）自动用 `memory.lint` 查一遍这一轮新写的段落，结果挂在回复下面（「它改完没自查，程序查到 N 处」，不花额度）。调了的话走完整流程：

助手改完正文要调 `self_check`：先用程序规则（`memory.lint`：假对比、书面连接语、总结式收尾、存疑句、问句或谜语标题、冒号两段式标题、图注带来源、编号串、强调句式）找，再把和这段文字相关的检查项（最多 14 条）给 Haiku 查语义层，查出问题自己改掉再查。要求模糊或改动面大时，助手先用决定卡片发"我理解你要……"，作者点「就这么改」才动手。

机制测试：`WB_MEMORY_FILE=某文件 node memtest.mjs` 可以在临时记忆文件上跑升降级、撤销、手改过滤、冲突这些机制（脚本在会话暂存区，必要时按 memory.mjs 顶部的说明重写一份）。

后台整理类的模型用 `ai.cheap('fast' | 'mid')` 取：默认接口是 Claude Code 时是 `claude-code::haiku` / `claude-code::sonnet`，是 Claude API 时是对应的 Haiku 5.5 / Sonnet 5.5；Haiku 返回的不是 JSON 就换 Sonnet 重跑一次。

助手还能只读地看作者别的作品（list_projects、search_projects、read_project）和选题广场（browse_plaza），文章项目还会自动带上「资料」页查到的内容。

小红书卡片的精修页右栏有「AI 助手 / 调元素」两个标签。卡片助手和文章助手是同一套（`agent.mjs` 按项目类型换工具：卡片用 view_cards 截图看效果、build_cards 渲染成图、copy_asset 把素材放进 img/）。前端的对话面板是公共组件 `mountChat()`。

## 文章模板

一套模板就是一份 `theme.css`，换模板只换样式，正文不动。

- 模板库在 `templates/article/<id>/`，由 `node tools/templates.mjs` 从开源主题转出来：墨滴 mdnice v1.4.0 的 15 套（GPL-3.0）和 doocs/md 的 3 套（WTFPL），原文件在 `templates/vendor/`。转换时保留配色、字体、标题、引语、加粗、链接、列表、表格的样式，去掉公众号不支持的写法（伪元素、背景图、CSS 变量、定位、动画），再按主题主色补上刊头、导语、目录、章节编号、图注、文末来源和签名的样式。
- 每篇文章自己的 `theme.css` 也算模板（「我的文章」），能套到别的文章上。
- 预览图：把模板套到 `templates/sample` 这篇示例文章上，走一遍真实构建再截图，存在 `data/template-previews/`。
- 入口：新建文章时选模板；写作页工具栏的调色板图标、项目页「更多」里的「换模板」（换完自动重新构建，可以恢复换之前的样式）；AI 助手的 list_templates / apply_template；命令行 `xy templates`、`xy new article 题目 --template 橙心`。
- 新建文章只复制骨架（build.mjs、package.json、依赖、样式），不再把别的文章的配图和封面源文件带过来。

## 技能（Skills）

`skills.mjs`。技能是一个带 `SKILL.md` 的文件夹，写着做某类事的方法和规则。来源有三个：工作台自己装的（`data/skills/`）、本机 Claude Code 的（`~/.claude/skills`）、本机 Agents 的（`~/.agents/skills`），同名只算一个。打开的技能会列进助手的系统提示（只列名字和描述），助手做相关的事之前用 load_skill 读全文。技能里的脚本、命令不会执行，只用文字说明。本机技能默认只开 humanizer-zh、lieflat-less-ai-tone、product-teardown，开关记在 `data/skills.json`。

能在 GitHub 上搜技能：用本机已登录的 `gh` 按文件名搜 SKILL.md（没登录时退回搜仓库）。安装是把 SKILL.md 所在的整个文件夹下载到 `data/skills/<名字>/`。助手只能“申请安装”（search_github_skills → request_install_skill），对话里出确认卡片，作者点了才装。入口：侧栏「技能」、助手栏顶部拼图按钮、`xy skills`。

## 选题广场

侧栏第一项。20 多个信息源按一手程度分四档排序：官方一手 > 社区一手 > 原创报道 > 转述（国内转载权重最低）。AI 挑的选题每个都要带官方或社区一手证据；可以读原文、深挖成写作简报、直接用它新建项目。代码在 `plaza.mjs`。

X（推特）走官方 API v2 的最近搜索（`x.mjs`），密钥存在 `data/x.json`（权限 600）或环境变量 `X_BEARER_TOKEN`。官方账号（设置里带 *）的帖子算官方一手，其余算社区一手。X 按读到的帖子收费，所以只拉新帖、不拉转发和回复，每次有条数上限（默认 100），两次之间至少隔几小时（默认 3）。在网页「信息源」弹窗或 `xy x` 里设置。

## 安全

- 服务只监听 127.0.0.1
- 网页的写操作要带启动时生成的令牌，别的网站没法借你的浏览器改数据
- 构建 / 打包命令网页改不了，只能用命令行设置
- 预览页放在沙箱 iframe 里

## 大纲页（先定大纲，再写正文）

- 新建时选「先查资料、出大纲」：项目进入大纲阶段（meta `phase: 'outline'`），直接打开「大纲」页，AI 先查资料、记进资料页，再把大纲写进 `outline.md`。
- 大纲页左边是可以直接改的大纲（小标题、要点、加一节；也能切到源码），右边是同一个 AI 助手。助手请求带 `stage: 'outline'`，这时它只改 `outline.md`，不动正文。
- 点底栏「大纲定了，开始写正文」：清掉大纲阶段，跳到写作页，自动发「照大纲写正文」。之后写作页的每一轮都会把 `outline.md` 带给 AI。
- 接口：`GET/PUT /api/projects/:id/outline`（和正文一样核对修改时间、自动存历史版本）。
