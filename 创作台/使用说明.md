# 创作台

DeepSeek Harness（DSH）里的内容创作插件。左侧栏点「创作台」，里面七页：选题广场、作品、视频、素材、AI 记忆、动态、设置。文章（资料 → 大纲 → 写作 → 体检 → 发布）、小红书卡片（大纲 → 浏览 → 精修）、视频脚本（多一步提词）都在「作品」里打开。

## 它怎么工作

- 插件自带后台程序（`workbench/` 文件夹），装上就能用。DSH 一启动，插件就在后台把它起来（默认端口 5295）。
- 写的文章、卡片、视频放在「文稿/创作台」文件夹里，在访达里能直接找到；设置、素材库、记忆、选题广场的数据放在 DSH 自己的目录里（`dataDir/workbench`），装了几个 DSH 就各存各的。
- AI 默认用 DSH 里配好的模型，不用另外填密钥。左下角能临时换模型，所有功能共用一个。
- 第一次用先去「设置 → 你的账号」填账号名字、定位和读者：AI 写稿、出选题会参考，公众号预览和封面上的署名也用它。不填也能用。

## 找选题

- 「最新动态」：国内外信息源的最新动态，顶上切「国内 / 国外 / 全部」，默认先看国内（36氪、虎嗅、IT之家、量子位、少数派、爱范儿、钛媒体、B 站等）。
- 「热榜」：百度热搜、抖音热榜、今日头条、B 站热门，各前 50 条，点「写成文章」直接带进新建作品。
- 「国内搜索」：公众号文章（搜狗微信）、B 站视频、中文新闻一起搜。写文章时 AI 助手查资料也会用国内搜索。
- 抓取老实写明是创作台，不冒充浏览器、不登录、不绕验证码；微博热搜、知乎热榜不登录拿不到，没接。

## 发布

文章的「发布」一步可以选：公众号、小红书、知乎、今日头条、微博。公众号是带格式复制直接粘；另外四个是一步步给标题、封面、正文和插图（知乎、头条、微博的正文带小标题、粗体、列表；小红书是纯文字加按顺序的配图，会提醒标题 20 字、正文 1000 字的上限）。

## 安装

DSH 里「插件 → 添加插件 → 安装第三方插件」，填这个文件夹的完整路径，装完重启 DSH。什么都不用改就能用。

想改的话，在 `cordis.patch.yml` 里加（都可以不写）：

- `projectsDir`：文章、卡片放在哪个文件夹，默认「文稿/创作台」。
- `port`：插件起的工作台用哪个端口，默认 5295。

## 文件

| 文件 | 管什么 | 改了以后 |
|---|---|---|
| `client.js` | 全部页面（DSH 插件底座的五段式，第 3 段是各页面） | 保存就生效，再点一下左侧入口 |
| `index.js` | 起工作台、转请求、传文件 | 重启 DSH |
| `host/gateway.js`、`host/bridge.js` | 让工作台用 DSH 的模型和联网 | 重启 DSH |
| `workbench/` | 后台程序：项目、AI、选题广场（`plaza.mjs`、国内热榜和搜索 `cn.mjs`）、发布（`post.mjs`）、视频 | 重启 DSH |

## 已知的限制

- 视频板块第一次用要点「一键装好」，自动下载视频工具（HyperFrames、ffmpeg，一百多 MB，装在插件的 `workbench/video/runtime/`，不用电脑上有 Node.js）。npm 官方源和国内镜像自动选。
- 做视频、拉片的 AI：电脑上装了 Claude Code 并登录就用它，不然用 DSH 里的模型。导出成片要电脑上有 Chrome（没有的话 HyperFrames 会自己下载一个浏览器，网络不好时可能很慢）。
- 口播剪辑和拉片里的「转文字」第一次要编译 whisper、下载语音模型，需要 Mac 装了 Xcode 命令行工具；没有的话转不了文字，拉片照样出分析，只是没有口播稿。
- 写作「体检」里的 AI 味指标要本机装了 lieflat-less-ai-tone 技能才有，没装只出 AI 通读的问题清单。
- 搜狗微信搜多了会要人机验证，这时公众号那一栏会提示「过一阵再搜」。
- 记忆「整理一下」「从手改里学」和全部复盘用的是默认模型，不跟左下角的选择走。
- 写作页按段落改：一次只能在一段里选中文字让 AI 改，不能跨段选。
